                  ⚡ Fusion round
                  
        
      
                  
      
                  The losers' work is not thrown away. Each loser's files the winner never touched, and up to 3 of its hunks in files the winner did change, are tried on top of the winning fix. A hunk must apply cleanly (no conflicts), every test must pass, then Clef must say it makes the change better. Last, the fused code is scored the same way as the forks and kept only if it scores at least the winner alone. Races judged before the score was added show no score. The tests run in a sandbox with read-only tokens; a second sandbox pushes only what passed.
